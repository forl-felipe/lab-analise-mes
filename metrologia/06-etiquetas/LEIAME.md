# Etapa 5 · Etiquetas QR Code

1. Confira antes as TAGs com observação na lista **Equipamentos** (coluna `ObservacaoCadastro`): TAGs repetidas e peneira sem TAG.
2. Abra `gerador-etiquetas.html` com dois cliques (funciona sem internet).
3. Cole o **Link da Web** do app Metrologia (Power Apps > Detalhes).
4. Cole a lista de equipamentos no formato `TAG; Descrição; Local`. O arquivo `lista-para-etiquetas.txt` do pacote de dados já vem nesse formato.
5. Escolha o tamanho, clique em **Gerar etiquetas**, toque em uma etiqueta para testar o link e imprima.

Use material resistente a limpeza e calor, principalmente perto das estufas. Para as peneiras, prefira etiquetas pequenas (60 × 30 mm) ou plaquetas presas ao aro.
